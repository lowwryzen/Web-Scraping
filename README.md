<br>

## ❔ Porque usar selenium

### O **Selenium** é uma ótima ferramenta de web scraping, e, diferente de outras ferramentas como **BeatifulSoup**, o diferencial do **Selenium** é que ele simula a interação do usuário com a página web, o que permite fazer automações simulando uma pessoa real.

> para intalar o selenium, basta abrir o terminal e digitar: <br> ``pip install selenium``
